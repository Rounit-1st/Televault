# TeleVault

**TeleVault** is a cloud-based file management system that uses **Telegram as the file storage backend** while **MongoDB stores only metadata and file indexing information**. It provides a familiar file explorer interface where users can upload, organize, search, preview, download, move, rename, and delete files and folders.

The project demonstrates how a messaging platform can be utilized as a storage layer while maintaining a structured virtual file system through a database.

# How It Works

1. User uploads a file.
2. Backend receives the file.
3. File is uploaded to Telegram using the Telegram Bot API.
4. Telegram returns a `file_id`.
5. MongoDB stores:

   * file name
   * owner
   * path
   * parent folder
   * Telegram `file_id`
   * size
   * MIME type
   * timestamps
6. During download:

   * Backend retrieves the stored `file_id`.
   * Telegram generates a temporary download URL.
   * The URL is returned to the frontend.
7. Users manage files through virtual folders stored in MongoDB.

# Advantages

---

# Limitations

* Telegram Bot API upload size limits apply.
* Telegram rate limits can affect bulk uploads.
* Download URLs generated by Telegram are temporary and must be refreshed when expired.
* Moving folders requires updating path references of all nested files and folders in the metadata database.
